# 日本株ポートフォリオ

保有している日本株の **取得単価・株数** を記録して、**株価・年間配当・株主優待** をまとめて確認できるアプリです。
「あと何株買えば優待のランクが上がるか」「配当がいくら増えるか」をその場で試算できます。

サーバーは不要。HTML / CSS / JavaScript だけの静的サイトで、データは端末のブラウザ内（localStorage）にだけ保存されます。

## できること

| 機能 | 内容 |
| --- | --- |
| 株価の取得 | 証券コードを入れて「株価を更新」。現在値・前日比・52週高安・配当実績を取得します |
| 取得単価と株数の記録 | 銘柄ごとに平均取得単価と株数を保存。買い増しすると平均取得単価を自動で再計算します |
| 配当の計算 | 1株あたり年間配当 × 保有株数。税引前／税引後（既定20.315%）を切り替えて表示 |
| 株主優待の表示 | 保有株数に応じた優待の段（ランク）を判定して表示。次の段まであと何株かも表示します |
| シミュレーション | 追加株数をスライダーで動かすと、必要資金・配当の増加額・優待のランクアップを即座に試算 |
| そのほか | 配当の受け取り月グラフ、一覧表モード、JSONの書き出し／読み込み、ダークモード、PWA（オフライン起動・ホーム画面追加） |

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages などに置いてもそのまま動きます）。
2. 「＋ 銘柄を追加」→ 証券コード（例：`7203`）・取得単価・株数を入力。
   コードを入れると銘柄名・単元株数・優待の候補が自動で入ります。
3. 「株価を更新」で現在値と配当実績を取得。初回だけ通信の確認ダイアログが出ます。
4. カードの「シミュレーション」で買い増しの試算。「買い増し」で実際の約定を記録。

初めて触るときは、メニュー（⋯）の「サンプルデータを追加」が手っ取り早いです。

## データの出どころと注意点

* **株価・配当**：Yahoo Finance のチャートAPI。ブラウザから直接は CORS で叩けないため、
  公開の中継サービス（r.jina.ai → allorigins → codetabs の順にフォールバック）を経由します。
  送信されるのは**証券コードだけ**で、保有株数や取得単価は送信されません。
  中継先は「設定」から自分のものに差し替えられます（`{url}` がエンコード済みの取得先URLに置き換わります）。
* **年間配当**：直近12か月に権利落ちした配当の**実績合計**です。会社予想ではありません。
  予想配当で計算したい場合は、銘柄の編集画面で「1株あたり年間配当」に手入力してください（手入力が優先されます）。
* **株主優待**：`js/presets.js` に入っている**参考データ**です。優待は新設・改悪・廃止が頻繁にあるため、
  内容が古い可能性があります。**必ず各社のIR・優待ページで確認**し、銘柄の編集画面から実際の内容に直してください。
  金額換算（年間の価値）は割引券・ポイントなどでは人により変わるので、自分の基準で入力するのがおすすめです。

本アプリは投資助言ではありません。表示される数字はすべて参考値です。

## iPhone（ホーム画面アプリ）での使い勝手

iPhone 16 Pro Max などのフルスクリーン端末を想定して、次の対策を入れています。

* Safari で開き、共有 → **「ホーム画面に追加」** でアプリとして起動できます（スタンドアロン表示・オフライン起動対応）。
* `viewport-fit=cover` ＋ `env(safe-area-inset-*)` で、ノッチとホームインジケータに文字がかぶらないようにしています。
* 入力欄のフォントサイズを 16px 以上に固定してあるので、**文字入力時に画面が勝手に拡大しません**。
* `touch-action: pan-y pinch-zoom` と `overscroll-behavior: none` で、**横／斜めスワイプの揺れや、端でのバウンドが起きません**（一覧表モードの中だけ横スクロールを許可）。ピンチでの拡大は従来どおり使えます。
* ダイアログを開いたときのフォーカスは見出しに当たるようにしてあり、**勝手にキーボードが立ち上がりません**。
* ボタンは `touch-action: manipulation` でダブルタップ拡大と長押しメニューを抑えています。

## ファイル構成

```
index.html                アプリ本体
privacy.html              プライバシーと外部通信の説明
css/style.css             見た目
js/presets.js             銘柄マスタ（社名・単元株数・優待の参考データ）
js/quotes.js              株価・配当の取得（中継サービスのフォールバックつき）
js/app.js                 状態管理・計算・描画
sw.js                     Service Worker（オフライン対応）
manifest.webmanifest      PWA の設定
assets/                   アイコン
tools/generate-icons.mjs  アイコンの生成（依存パッケージなし）
```

アイコンを作り直すときは次を実行します。

```bash
node tools/generate-icons.mjs
```

## 計算式

* 評価額 = 現在値 × 株数
* 評価損益 = 評価額 − 取得金額（取得金額 = 平均取得単価 × 株数）
* 年間配当 = 1株あたり年間配当 × 株数（税引後は × 0.79685）
* 配当利回り = 1株あたり年間配当 ÷ 現在値
* 取得比利回り（YOC）= 1株あたり年間配当 ÷ 平均取得単価
* 総合利回り = （年間配当 + 優待の年間価値）÷ 取得金額
* 買い増し後の平均取得単価 =（現在の取得金額 + 追加株数 × 約定単価）÷ 合計株数
