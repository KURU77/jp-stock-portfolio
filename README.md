# 日本株ポートフォリオ

**→ https://kuru77.github.io/jp-stock-portfolio/ （インストール不要・そのまま使えます）**

保有している日本株の **取得単価・株数** を記録して、**株価・年間配当・株主優待** をまとめて確認できるアプリです。
「あと何株買えば優待のランクが上がるか」「配当がいくら増えるか」をその場で試算できます。

サーバーは不要。HTML / CSS / JavaScript だけの静的サイトで、データは端末のブラウザ内（localStorage）にだけ保存されます。

## できること

| 機能 | 内容 |
| --- | --- |
| 銘柄のチャート | 保有銘柄のカードから、株価の折れ線（1か月〜1年）を開けます。平均取得単価の線つきで、タップすればその日の終値が出ます |
| 損益のまとめ | 専用ページ（`profit.html`）で、年ごとの確定した利益（実現損益）と、まだ売っていない分の含み損益を確認できます |
| 端末間の同期 | Googleアカウントでログインすると、パソコン・iPad・iPhone でデータを揃えられます。置き場は自分のGoogleドライブで、サーバーは使いません |
| AIレビュー（おまけ） | 自分の Gemini API キーを入れると、ポートフォリオの要約を渡して分散・配当・NISAの使い方などの気づきを整理してもらえます |
| 資産のグラフ | 専用ページ（`chart.html`）で、資産合計と評価損益の推移、銘柄別の損益、銘柄・口座の構成比をグラフで確認できます |
| 夜間PTS・場中の値動き | 専用ページ（`night.html`）で、当日のザラ場5分足チャート・後場の動き・夜間PTSの損益をまとめて確認できます |
| 銘柄の検索 | 東証と名証の全上場銘柄（4,508件）から、コードでも銘柄名でも検索できます。`186A`（アストロスケール）のような英数字コード、`ispace`・`神島化学` のような社名にも対応。名証にしか上場していない64銘柄（岡谷鋼機・名工建設 など）も、名証の日報から終値を取ります |
| 口座で分けて管理 | 特定口座・NISA（成長投資枠／つみたて投資枠）・一般口座を区別。口座ごとの評価額・損益・配当を並べて確認でき、NISA の配当は非課税として計算します |
| 毎月の積み立て | 銘柄・口座・毎月の金額・買付日を登録。いまの株価で毎月何株買えるか、優待に届くのはいつか、続けた場合の株数と配当を試算します |
| 投資余力（現金） | 口座ごとの買付余力を記録。資産合計（株＋現金）や、買い増しで足りるかどうかの判定に使います |
| 売却の記録 | 売却株数・単価・手数料を入れると、実現損益と税額の目安を計算して履歴に残します。受取額は投資余力に自動で加算されます |
| 株価の取得 | 証券コードを入れて「株価を更新」。現在値・前日比・52週高安・配当実績を取得します |
| 取得単価と株数の記録 | 銘柄ごとに平均取得単価と株数を保存。買い増しすると平均取得単価を自動で再計算します |
| 配当の計算 | 1株あたり年間配当 × 保有株数。税引前／税引後（既定20.315%）を切り替えて表示 |
| 株主優待の表示 | 保有株数に応じた優待の段（ランク）を判定して表示。次の段まであと何株かも表示します |
| シミュレーション | 追加株数をスライダーで動かすと、必要資金・配当の増加額・優待のランクアップを即座に試算 |
| そのほか | 配当の受け取り月グラフ、一覧表モード、JSONの書き出し／読み込み、ダークモード、PWA（オフライン起動・ホーム画面追加） |

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages などに置いてもそのまま動きます）。
2. 「＋ 銘柄を追加」→ 証券コード（例：`7203`）・取得単価・株数を入力。
   コードを入れると銘柄名・単元株数・優待の候補が自動で入ります。
3. 「株価を更新」で現在値と配当実績を取得。初回だけ通信の確認ダイアログが出ます。
4. カードの「シミュレーション」で買い増しの試算。「買い増し」で実際の約定を記録。

初めて触るときは、メニュー（⋯）の「サンプルデータを追加」が手っ取り早いです。

## 資産のグラフ

ヘッダーの「📊 グラフ」から開きます（`chart.html`）。外部ライブラリは使わず、SVGで描いています。

* **資産の推移（過去1年）**：保有銘柄の日足を取得して、資産合計・評価額・取得金額の推移を折れ線で描きます。3か月／6か月／1年で期間を切り替えられます。
  * **「取得日を反映する」**（既定ON）にすると、取得日・買付日・売却日をもとに「その日に実際に持っていた株数」で計算します。**買う前の値動きはグラフに入りません**。取得金額は買うたびに階段状に増え、グラフはいちばん古い買付日から始まります。
  * 現金は「いまの残高から、その後の売買を巻き戻した推定値」です。買う前はその代金を現金で持っていたものとして扱うので、買った日に資産合計が跳ね上がりません（入出金までは分からないので目安です）。
  * チェックを外すと、従来どおり「いまの保有株数のまま1年前から持っていた場合」で描きます。
  * **タップ（クリック／ドラッグ）でその日の日付と金額**（資産合計・評価額・取得金額・評価損益）を十字線とふきだしで表示します。
  * **2本指でつまむと拡大・縮小**、2本指でなぞると左右に移動。マウスホイールでも拡大・縮小できます。＋／−／全体のボタンもあります。
  * いちばん拡大すると**6営業日ぶん（日足で1日ずつ）**まで寄れます。60営業日以下まで拡大すると、日ごとの点が線の上に出ます。
* **記録された資産**：アプリを開いて株価を更新するたびに、その日の資産合計・評価額・取得金額・現金を**1日1件だけ**記録しています。こちらは売買や入金も反映された実際の推移で、2日目から線になります。こちらもタップと拡大に対応しています。
* **銘柄別の評価損益**：中央を0円とした左右の棒グラフ。損益額の大きい順に並びます。
* **資産の内訳**：銘柄別（上位7件＋その他）と口座別（株＋現金）のドーナツグラフ。

## 画面の構成

* ヘッダーの下に**ページの切り替えタブ**（保有・損益・グラフ・夜間PTS・同期）があり、どのページからでも行き来できます。
* 保有ページの上部に**よく使う操作**（銘柄を追加・積み立てを追加・投資余力を入力）を並べています。メニュー（⋯）の中にもあります。
* 「投資余力」のタイルはそのまま押すと入力画面が開きます。
* 積み立てのパネルは、保有一覧のすぐ下に置いています。
* 狭い画面では、ヘッダーのボタンは記号だけになり、損益の表はカード型に組み替わります（横スクロールしません）。

## 銘柄のチャート

保有銘柄のカードの「📈 チャート」（一覧表モードでは「チャート」）から開きます。

* 終値の折れ線を **1か月／3か月／6か月／1年** で切り替えられます。
* **平均取得単価が点線**で重なるので、いまの株価が自分の買値のどちら側かが一目で分かります。
* タップ（ドラッグ）すると、その日の日付・終値・取得単価との差が出ます。
* 期間の高値・安値、評価額、評価損益も並びます。日足はグラフページと同じ置き場を使い回し、12時間はそのまま使います。

## 損益のまとめ

メニュー（⋯）の「💰 損益のまとめ」から開きます（`profit.html`）。売買の記録から2種類の損益をまとめます。

* **含み損益**：いま持っている分の「現在値 − 平均取得単価 × 株数」。銘柄ごと・口座ごとの内訳と、取得日も並びます。
* **年ごとの確定した利益**：記録した売却を年で集計し、棒グラフと表で出します。売却代金・実現損益・課税口座分・NISA分・税額の目安・手取りが並びます。
* **月ごとの内訳**：年を選ぶと、その年の月別の棒グラフと売却の明細が出ます。
* **税額は年内で通算してから計算**します。売却1件ずつに税をかけて足すと、同じ年の損と相殺されないぶん多く出てしまうためです。
  源泉徴収された額と目安に差があるときは、その差も表示します（特定口座・源泉徴収ありなら年末や確定申告で調整されます）。
* 配当は受け取りの履歴を持っていないため、損益には含めていません（いまの保有から見た年間の見込み額だけ参考に出します）。

## Googleアカウントでの同期（パソコン・iPad・iPhone）

メニュー（⋯）の「🔄 Google同期」から設定します（`sync.html`）。
サーバーを持たないアプリなので、データの置き場は**あなた自身のGoogleドライブ**です。
データはドライブの**アプリ専用領域**（appDataFolder）に置かれます。ドライブの画面には出ず、このアプリ以外からは見えません。権限も `drive.appdata` だけなので、ほかのファイルには触れられません。

### 使いかた

1. メニュー（⋯）の「🔄 Google同期」を開く
2. 「Googleでログイン」を押して、自分のGoogleアカウントでログインする
3. ほかの端末（iPad・iPhone・パソコン）でも同じ手順で同じアカウントにログインする

これだけです。OAuthクライアントはアプリに埋め込んであるので、設定はいりません。

### 動き

* 変更すると数秒後に自動でアップロードし、アプリを開いたときに他の端末の変更を取り込みます。
* 銘柄・売却・買付・積み立ては**1件ごと**に新しいほうを採ります。別々の端末で別の銘柄を直しても、どちらも残ります。削除は墓標として記録するので、消したものが他の端末から復活しません。
* 投資余力は口座ごと、設定は丸ごと1単位で、あとから変えたほうを採ります。
* ログインの有効期限は約1時間で、切れたら自動で取り直します。取り直せないときだけ、もう一度ログインしてください。
* LINEやInstagramのアプリ内ブラウザはGoogleがログインを弾くので、Safariなどで開いてください。
* 同期するもの：保有銘柄・売却と買付の記録・積み立て・投資余力・記録した資産の推移・設定
* 同期しないもの：**GeminiのAPIキー**、夜間PTSの手入力、株価と日足のキャッシュ、ダークモードなどの見た目

## AIレビュー（おまけ機能）

メニュー（⋯）の「🤖 AIレビュー」から開きます（`review.html`）。Google の **Gemini API** に自分のポートフォリオの要約を渡して、気づきを整理してもらう機能です。

* **APIキーは自分で用意します**（Google AI Studio で発行）。キーはこの端末のブラウザ内（localStorage）にだけ保存し、通信先は Google の API だけです。中継サービスは通しません（キーを第三者に渡さないため）。
* **送信するテキストは画面にそのまま表示**しています。銘柄名を伏せる／金額を伏せる／積み立てと余力を含めない、の3つで送る内容を減らせます。
* モデルは既定が `gemini-2.5-flash`。「使えるモデルを取得」でアカウントで利用可能なモデル一覧を引いて選べます。
* プロンプトでは「**売買の推奨をしない**」「将来予測をしない」「データから読み取れないことは推測しない」よう指示し、最後に投資助言ではない旨を書かせています。
* 出てくる文章は生成AIの出力です。事実と異なる可能性があり、**投資助言ではありません**。
* ブラウザに保存する以上、その端末を使える人はキーを読み出せます。用途を限定した使い捨てのキーを使い、不要になったら Google 側でも削除してください。API利用料はご自身の Google アカウントに請求されます。

## 積み立ての登録手順

1. トップページ下のほうにある「毎月の積み立て」パネルの **「＋ 積み立てを追加」**（またはメニュー ⋯ の「積み立てを追加」）を押します。
2. **証券コードか銘柄名**で銘柄を選びます（例：`7203`、`ispace`）。
3. **口座**（特定／NISA成長／NISAつみたて／一般）を選びます。
4. **毎月の金額**（例：30000）と **買付日**（毎月の何日か。1〜28）、**買付単位**（単元未満株なら1株）を入れます。
5. 「保存」を押すと登録され、いまの株価で毎月何株買えるか・優待に届く時期・続けた場合の株数と配当が表示されます。

登録した積み立ては、毎月の買付日が来ると「今月分が未記録です」と表示されます。実際に約定したら「買付を記録」から金額と約定単価を入れると、保有株数・平均取得単価・投資余力に反映されます。

## 毎月の積み立て

「毎月◯円ぶん、この銘柄を買い続ける」設定を登録できます（SBIのかぶツミ、楽天のかぶツミのような金額指定の積み立てを想定）。

* 銘柄・**口座（特定／NISA成長／NISAつみたて／一般）**・毎月の金額・買付日・買付単位（単元未満株なら1株）を登録します。
* 登録すると、その銘柄が0株の状態で保有一覧に用意され（「積立中」バッジ）、株価・配当・優待の情報がそのまま使えるようになります。
* カードに出るもの：
  * **いまの株価なら毎月何株買えるか**と、1回あたりの金額・余り（例：30,000円 → 8,170円 × 3株 = 24,510円、余り 5,490円）
  * 今月の状態（記録済み／未記録／次の買付日まであと何日）
  * 積立回数・累計投資額・累計株数・平均取得単価
  * **優待に届くのはいつか**（例：「このペースなら あと34か月（2029年7月ごろ）で100株に届きます」）
  * 1年後／3年後／5年後の投資額・保有株数・年間配当（いまの株価と配当が続く前提）
* **NISAの年間投資枠**（成長240万円・つみたて120万円）に対して、その積み立ての年額が何%を使うかをゲージで表示します。超える設定にすると警告します。
* 「買付を記録」で実際の約定を登録します。金額と約定単価を入れると**買える最大の株数**を計算し（日本株に小数の株はないため）、保有株数と平均取得単価を更新して、支払額を投資余力から差し引きます。
* 停止／再開、編集、削除ができます。削除しても買付の記録と保有株数はそのまま残ります。

## 投資余力と売却

### 投資余力（現金）

メニュー（⋯）の「投資余力を入力」から、**口座ごとの買付余力**を入れておけます。

* サマリーに「投資余力」と「資産合計（株＋現金）」が出ます。口座別サマリーにも口座ごとの余力と合計が並びます。
* 買い増しシミュレーションで「余力 486,667円 → 173,467円」のように、その買い増しで余力が足りるか（いくら不足するか）が分かります。
* 入出金は**増減額だけ**を入れれば反映できます（残高を計算し直す必要はありません）。口座ごとに「入金 ＋／出金 −」を選び、金額を入れると反映後の残高がその場で出ます。残高そのものを入れ直したいときは「残高を直接入力する」にチェックを入れてください。
* 売却を記録すると受取額が自動で加算され、買い増しを記録すると支払額が差し引かれます（どちらもダイアログのチェックで切り替えられます）。

### 売却の記録

銘柄カードの「売却」から、売却株数・約定単価・手数料・売却日を記録します。

* **実現損益** =（売却単価 − 平均取得単価）× 株数 − 手数料。売っても残った株の平均取得単価は変わりません。
* **税額の目安**は課税口座のみ、利益が出たときだけ計算します（NISAは非課税と表示）。「源泉徴収する」にチェックを入れておくと、受取額から税額を差し引いた金額が投資余力に入ります（特定口座・源泉徴収ありの動きに合わせています）。
* 全部売ると銘柄は一覧から消えますが、記録は残っています。ツールバーの「売却済みも表示」でいつでも確認でき、**売却履歴の「取り消し」で株数と余力を元に戻せます**（入力ミスの復旧用）。
* **売ったあとに同じ銘柄を買い直した場合**は、そのまま「＋ 銘柄を追加」で登録できます（同じ口座でも可）。0株になった古い記録は売却履歴とつながったまま残り、買い直しぶんは別の持ち分として足されるので、グラフの推移も正しく積み上がります。
* 「売却履歴（実現損益）」のパネルに、今年の実現損益・税額の目安・全期間の合計が並びます。口座で絞り込むと履歴も連動します。
* 手数料は買い増しでも入力でき、取得価額に含めて平均取得単価を計算します。

実際の税額は他の損益との通算や損失の繰越で変わるため、あくまで目安としてお使いください。

## 夜間PTS・場中の値動きページ

ヘッダーの「🌙 夜間PTS」から開きます（`night.html`）。夜と昼の値動きを追うことに絞ったページです。

* **セッション時計**：いまが前場／昼休み／後場／夜間PTSのどれかを表示し、終了までの残り時間と一日の進み具合を帯で示します。
* **当日のミニチャート**：東証の5分足を折れ線で表示。前場と後場を別の線にしているので、昼休みを挟んだギャップがそのまま見えます。前日終値は点線、入力した夜間PTS株価は青い点線で重なります。
* **昼からの動き**：前日終値・寄付・前引・後場寄・高値・安値を並べ、「後場の動き（前引比）」と保有株数ぶんの損益を出します。ポートフォリオ全体の「本日の東証」「後場の動き」も合計で表示します。
* **夜間PTS**：株価は**手入力**です。入力すると東証終値との差・変化率・保有株数ぶんの損益・PTS反映後の評価額が自動計算されます。入力はその夜のセッション（翌朝6時まで）だけ保存され、翌営業日には自動で消えます。

### なぜ夜間PTSだけ手入力なのか

銘柄別のPTS株価を自動取得できる無料の窓口が見つからなかったためです。

* **株探・Yahoo!ファイナンス**：PTS株価は載っていますが、CORS中継サービス経由のアクセスをbot判定でブロックします（CAPTCHA / HTTP 500）。この回避はしません。
* **ジャパンネクスト証券**（PTS運営元）：サイトに「掲載情報の転用、複製、販売、加工、再利用および再配信することを固く禁じております」と明記されているため、取り込みません。
* Yahoo Finance のAPIは日本株の時間外気配を持っていません（`hasPrePostMarketData: false`）。

そのため各銘柄に「PTSを見る」ボタンを置き、株探のページをワンタップで開いて、見えた株価をそのまま入力する形にしています。

## 口座の分け方

銘柄ごとに **特定口座 / NISA（成長投資枠）/ NISA（つみたて投資枠）/ 一般口座** を選びます。

* **同じ銘柄を複数の口座で持てます**。「特定口座のトヨタ200株」と「NISAのトヨタ100株」を別々に登録してください（株価は1回の通信で両方に反映されます）。
* 「配当を税引後で表示」にすると、**NISA口座だけ非課税（税率0%）**、特定・一般口座は設定の税率（既定20.315%）で計算します。
* 口座別サマリーのカードを押すと、その口座だけに絞り込めます（もう一度押すと解除）。上部の合計値・配当カレンダー・優待一覧も絞り込みに連動します。
* NISA を使っていると、**生涯非課税保有限度額（簿価1,800万円・うち成長投資枠1,200万円）の使用状況**がゲージで表示されます。年間投資枠（成長240万円・つみたて120万円）は購入年ごとの管理が必要なため対象外です。
* 口座を選ばずに作った古いデータは、特定口座として読み込まれます。

## データの出どころと注意点

* **銘柄マスタ**：`js/stocks.js` に **4,508銘柄**。出どころは2つです。
  * 東証ぶん … JPXの[東証上場銘柄一覧](https://www.jpx.co.jp/markets/statistics-equities/misc/index.html)（data_j.xls、2026年7月31日時点で4,444銘柄）
  * 名証ぶん … 名古屋証券取引所の[銘柄検索API](https://www.nse.or.jp/api/stock/search.json)（323銘柄。プレミア166・メイン131・ネクスト24・ETF2）

  名証の323銘柄のうち **259銘柄は東証にも上場**しているので、残る **64銘柄が名証単独**です
  （岡谷鋼機・名工建設・中部日本放送・マルサンアイ・ＮＩＴＴＯＨ など）。JPXの一覧には入らないため、
  以前は検索しても出てきませんでした。
  証券コードは4桁の数字だけでなく `186A` のような英数字にも対応。原本は銘柄名が全角（`ｉｓｐａｃｅ`）なので、半角に直して収録しています。
  新規上場・社名変更に追随するには `node tools/build-stock-master.mjs` を実行してください（`npm install xlsx` が必要）。
  名証ぶんだけ入れ替えるなら `node tools/build-stock-master.mjs --nse-only`（xlsx は不要）。
* **株価・配当**：Yahoo Finance のチャートAPI。ブラウザから直接は CORS で叩けないため、
  公開の中継サービス（r.jina.ai → allorigins → codetabs の順にフォールバック）を経由します。
  送信されるのは**証券コードだけ**で、保有株数や取得単価は送信されません。
  中継先は「設定」から自分のものに差し替えられます（`{url}` がエンコード済みの取得先URLに置き換わります）。
* **名証単独銘柄の株価**：取得先が東証ぶんと違います。上から順に試します。

  1. **Yahoo!ファイナンス日本版**（`https://finance.yahoo.co.jp/quote/7485.N`）…
     15分ディレイの現在値・前日終値・始値/高値/安値・出来高・**会社予想の1株配当と利回り**・年初来高値/安値・単元株数が取れます。
     日足は同サイトの時系列ページを13ページ並べて取り、**1年ぶん（約242営業日）**を作ります。
  2. **名証の[日報PDF](https://www.nse.or.jp/market/condition/report/)**（`…/report/files/YYYYMMDD.pdf`）…
     1でまだ値が出ていないとき（その日まだ約定していない銘柄、寄り付き前、上場したて）に使います。
     1つのPDFに名証の全323銘柄が載っているので、**銘柄コードすら送信しません**。取得は1日1回で結果はブラウザに保存し、
     当日ぶんが無ければ前の営業日へ最大6営業日さかのぼります（祝日の判定はせず、PDFの有無で判断）。
     売買が成立しなかった銘柄は**最終気配**、それも無い銘柄は**参考値**になります（10/07は約定63・気配250・参考値10）。

  なお Yahoo Finance の**英語API**（`query1.finance.yahoo.com`）には名証単独銘柄がありません。
  `.T` / `.N` / `.NG` などどの接尾辞でも404で、接尾辞なしだと中身の無い別物（通貨`null`・2019年で止まった`MUTUALFUND`）が返ります。
  銘柄名で検索しても出てこないので、東証ぶんと同じ経路は使えません。

  * 表示は「〇分前・名証15分ディレイ」、日報から読んだときは「名証の日報 10/07 の終値」のように、何の値かが分かるようにしてあります。
  * 配当は**会社予想**なので、東証ぶん（直近12か月の実績）とは別物です。カードに「会社予想」と出ます。
    権利確定月までは分からないので、配当カレンダーには載りません。
  * 夜間PTSページの5分足は名証単独銘柄では使えません。
* **年間配当**：直近12か月に権利落ちした配当の**実績合計**です。会社予想ではありません。
  予想配当で計算したい場合は、銘柄の編集画面で「1株あたり年間配当」に手入力してください（手入力が優先されます）。
* **株主優待**：`js/presets.js` に入っている**参考データ**です。優待は新設・改悪・廃止が頻繁にあるため、
  内容が古い可能性があります。**必ず各社のIR・優待ページで確認**し、銘柄の編集画面から実際の内容に直してください。
  金額換算（年間の価値）は割引券・ポイントなどでは人により変わるので、自分の基準で入力するのがおすすめです。

本アプリは投資助言ではありません。表示される数字はすべて参考値です。

## iPhone（ホーム画面アプリ）での使い勝手

iPhone 16 Pro Max などのフルスクリーン端末を想定して、次の対策を入れています。

* Safari で開き、共有 → **「ホーム画面に追加」** でアプリとして起動できます（スタンドアロン表示・オフライン起動対応）。
* `viewport-fit=cover` ＋ `env(safe-area-inset-*)` で、ノッチとホームインジケータに文字がかぶらないようにしています。
* 入力欄のフォントサイズを 16px 以上に固定してあるので、**文字入力時に画面が勝手に拡大しません**。
* `touch-action: pan-y pinch-zoom` と `overscroll-behavior: none` で、**横／斜めスワイプの揺れや、端でのバウンドが起きません**（一覧表モードの中だけ横スクロールを許可）。ピンチでの拡大は従来どおり使えます。
* ダイアログを開いたときのフォーカスは見出しに当たるようにしてあり、**勝手にキーボードが立ち上がりません**。
* ボタンは `touch-action: manipulation` でダブルタップ拡大と長押しメニューを抑えています。

## 計算式

* 評価額 = 現在値 × 株数
* 評価損益 = 評価額 − 取得金額（取得金額 = 平均取得単価 × 株数）
* 年間配当 = 1株あたり年間配当 × 株数（税引後は × 0.79685）
* 配当利回り = 1株あたり年間配当 ÷ 現在値
* 取得比利回り（YOC）= 1株あたり年間配当 ÷ 平均取得単価
* 総合利回り = （年間配当 + 優待の年間価値）÷ 取得金額
* 買い増し後の平均取得単価 =（現在の取得金額 + 追加株数 × 約定単価 + 手数料）÷ 合計株数
* 実現損益 =（売却単価 − 平均取得単価）× 売却株数 − 手数料
* 売却時の税額の目安 = 実現損益 × 税率（課税口座で利益が出たときのみ／NISAは0）
* 受取額 = 売却代金 − 手数料 −（源泉徴収する場合の税額）
* 資産合計 = 評価額 + 投資余力
* 年の税額の目安 = max(0, その年の課税口座の実現損益の合計) × 税率（年内で損益通算してから計算）
* 取得日を反映したときの評価額(t) = Σ その日に持っていた株数 × その日の終値
* 取得日を反映したときの取得金額(t) = Σ（その日までの買付金額 + 手数料）− Σ その日までの売却分の取得原価
* 積み立ての買付株数 = floor(買付金額 ÷ 約定単価 ÷ 買付単位）× 買付単位
* 優待に届くまでの月数 = ceil（次の段に足りない株数 ÷ 毎月買える株数）
