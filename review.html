Gemini API の設定

Google AI Studio で発行した自分のAPIキーを使います。キーはこの端末のブラウザ内（localStorage）にだけ保存され、 通信先は Google の API だけです（このアプリの作者や中継サービスには渡りません）。

ブラウザに保存する以上、この端末を使える人はキーを読み出せます。 用途を限定した使い捨てのキーを使い、不要になったら Google AI Studio 側でも削除してください。 APIの利用料はご自身の Google アカウントに請求されます（無料枠あり）。
