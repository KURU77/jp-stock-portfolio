手動で入れ替える

いつもは自動で新しいほうに合わせます。食い違ったときや、ひとつの端末の内容で揃えたいときだけ使ってください。

取り込みの前に、この端末の内容は1世代だけ控えを取ります（「直前の内容に戻す」で戻せます）。 大事なデータはポートフォリオ側の「JSONで書き出し」でも保存しておくと安心です。

最初の設定（1回だけ）

このアプリはサーバーを持たないので、データの置き場はあなた自身のGoogleドライブです。 そのためのアクセス許可（OAuthクライアントID）を、ご自身のGoogleアカウントで1つ作ってください。 作ったIDはこの端末のブラウザ内にだけ保存されます。

  1. Google Cloud Console でプロジェクトを作る（名前は何でも構いません）。
  2. 「APIとサービス」→「ライブラリ」で Google Drive API を有効にする。
  3. 「OAuth同意画面」を作る。ユーザーの種類は「外部」、アプリ名と自分のメールを入れて保存。 テストのままにする場合は「テストユーザー」に自分のGoogleアカウントを追加してください。
  4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類はウェブアプリケーション。
  5. 承認済みのJavaScript生成元に、このページの場所を登録する：
    —
    リダイレクトURIの登録は不要です。
  6. できたクライアントID（…apps.googleusercontent.com）を下に貼り付けて保存。

同期されるもの・されないもの

同期する

  • 保有銘柄（取得単価・株数・取得日・優待の設定）
  • 売却の記録と買付の記録
  • 毎月の積み立ての設定と実績
  • 投資余力（口座ごとの現金）
  • 記録された資産の推移
  • 設定（配当の税率、中継サービスの指定）

同期しない

  • GeminiのAPIキー（端末ごとに入れてください）
  • 夜間PTSの手入力（その晩だけのもの）
  • 株価・日足のキャッシュ（各端末で取り直せます）
  • ダークモードなどの見た目の設定

アプリが読み書きするのは、ドライブ上の jp-stock-portfolio-sync.json だけです（drive.file 権限）。 ほかのファイルは見えません。作者や第三者のサーバーは経由せず、通信先はGoogleだけです。
